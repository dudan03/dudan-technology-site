# Dudan Technology website

A responsive, self-contained marketing website for Dudan Technology Private Limited.

## Open locally

Open `index.html` in a modern browser. No installation, build command, or server is required.

## Included interactions

- Responsive mobile navigation
- Interactive project cost estimator
- WhatsApp-ready estimate and contact form (to +91 7008872724)
- Interactive AI chatbot demo prompts
- FAQ accordions and smooth in-page navigation

## Files

- `index.html` — site structure and content
- `styles.css` — responsive visual design
- `script.js` — calculator, WhatsApp forms, chatbot demo, and mobile menu
